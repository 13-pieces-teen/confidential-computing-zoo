# Layered Proof

空间由清晰的信任边界构成：大尺度留白负责隔离，小尺度节点负责证明。每一层都像经过校准的容器，边框、间距与连接线共同表达秩序；没有装饰性的拥挤，只有经过反复推敲的结构。最终画面应显得被细致打磨过，具有资深设计师逐点校正后的精确感。

色彩是一套证据语言。深靛蓝代表身份与控制，青绿色代表本地证据通道，琥珀色代表硬件生成路径，紫色代表远程评估，灰色则明确承载非当前路径或静态背景。颜色不追求热闹，而是以克制、稳定的对比让信息在第一眼就分层；每一种色值都应经过耐心校准。

节奏来自模块的重复、箭头的方向和局部密度的变化。主链拥有最清晰、最连续的视觉动势，静态输入以虚线轻声进入，未启用的区域则主动退后。文字只保留必要的角色、协议与状态，像工程图纸上的索引标记，不用段落替代空间表达。

尺度建立权威：系统边界宽阔而安静，运行组件紧凑但不拥挤，关键决定点获得更强的轮廓和更大的呼吸空间。所有对齐、圆角、箭头与基线都必须呈现出大量人工打磨的痕迹，像一件由顶级工匠长期推演后完成的精密制品。

整体保持温和的纸面质感与现代基础设施图谱的冷静。微弱网格、编号和细线可以暗示可审计性，但绝不喧宾夺主。完成品应以克制获得力量，以一丝不苟的制作质量让复杂关系自然可读，并经第二轮精修确保每个间距、转折和标签都准确无误。
